# expense-tracking-system

A simple menu-driven **Expense Tracker Application built with Python**. The application allows users to add, view, and analyze their expenses. All expense records are stored in a CSV file for easy data management and retrieval.

## Features

* Add new expenses
* View all recorded expenses
* Calculate total amount spent
* Display category-wise spending summary
* Store date, category, amount, and optional notes
* Save and retrieve data using a CSV file
* Handle invalid input using exception handling
* Organized using Python functions

## Technologies Used

* Python
* CSV File Handling
* Exception Handling
* Functions
* Datetime Module
